# Robin's Homebrew Tap

Homebrew formulae and casks maintained by [Robin](https://github.com/robin-liquidium).

## Install

Install Dayline directly:

```sh
brew install --cask robin-liquidium/tap/dayline
```

Install Linear TUI directly:

```sh
brew install robin-liquidium/tap/linear-tui
```

Or tap this repository first:

```sh
brew tap robin-liquidium/tap
brew install linear-tui
```
